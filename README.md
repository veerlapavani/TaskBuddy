# TaskBuddy

TaskBuddy is a simple Task Management web application built with Django and Python.

## Features

* Create new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Set task priority
* Add task categories
* View task progress
* Simple and user-friendly dashboard

## Technologies Used

* Python
* Django
* HTML5
* CSS3
* SQLite
* Git & GitHub

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/veerlapavani/TaskBuddy.git
```

2. Open the project folder:

```bash
cd TaskBuddy
```

3. Create and activate a virtual environment:

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

4. Install Django:

```bash
pip install django
```

5. Run migrations:

```bash
python manage.py migrate
```

6. Start the development server:

```bash
python manage.py runserver
```

7. Open:

```text
http://127.0.0.1:8000/
```

## Project Purpose

This project was developed to practice Django, Python, database operations, CRUD functionality, templates, and basic web application development.
